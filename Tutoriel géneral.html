🎙️ Guide Complet du Contrôleur CAT IC-7300

Installation, configuration matérielle, cartes son système et manuel d'instruction

Introduction

Bienvenue dans le guide d'utilisation de votre contrôleur d'émetteur-récepteur Icom IC-7300 écrit en Rust. Ce logiciel a été conçu pour simplifier l'exploitation quotidienne de votre station radioamateur. Entièrement asynchrone, il vous permet de piloter la radio, de visualiser le spectre électromagnétique en temps réel, de gérer une base de données de fréquences et d'automatiser vos lancements d'appels de manière fluide.

Ce guide est rédigé de façon exhaustive afin d'accompagner pas à pas les utilisateurs novices dans le paramétrage de leur station.

1. Installation et Prérequis Système

Avant de lancer l'application pour la première fois, quelques étapes simples d'installation matérielle et logicielle sont requises sur votre ordinateur sous Windows (64 bits).

1.1 Raccordement physique

Reliez votre émetteur-récepteur Icom IC-7300 à un port USB libre de votre PC à l'aide d'un câble USB standard (type A vers type B). Ce câble unique transporte à la fois les commandes de contrôle (CAT) et les signaux audio (carte son interne).

1.2 Installation du pilote de communication (Driver Silicon Labs)

Pour que Windows reconnaisse le câble USB et crée un port de communication virtuel (ex : COM3), vous devez installer le pilote de la puce intégrée au poste :

  • Allez sur le site officiel de Silicon Labs ou de l'assistance Icom.
  • Téléchargez et installez le pilote nommé CP210x USB to UART Bridge VCP Drivers pour Windows.
  • Une fois installé, débranchez puis rebranchez le câble USB de la radio.
[IMAGE 1 : Le Gestionnaire de périphériques Windows] Illustration montrant l'emplacement du port virtuel "Silicon Labs CP210x... (COMx)" sous la catégorie "Ports (COM et LPT)".

1.3 Arborescence locale et dossier "samples"

L'application s'exécute de manière portable (sans installation lourde). Lors de son premier lancement, elle crée automatiquement dans son répertoire :

  • La base de données SQLite memories.db pour stocker vos réglages et mémoires.
  • Un dossier nommé samples/. C'est dans ce dossier que seront automatiquement copiés tous les fichiers MP3 d'appels que vous déciderez d'utiliser dans l'application.

2. Paramétrage Windows des Cartes Son (Mode Non Exclusif)

L'IC-7300 intègre sa propre carte son (codec USB). Pour que vos fichiers MP3 d'appels automatiques ou vos logiciels de trafic (comme WSJT-X, MMSSTV) puissent émettre et recevoir simultanément sans blocage, il est indispensable de désactiver le "Mode Exclusif" dans Windows et de régler l'échantillonnage de manière rigoureuse.

2.1 Éliminer le blocage du "Mode Exclusif"

Par défaut, Windows permet au premier logiciel lancé de s'approprier exclusivement la carte son, générant des erreurs d'initialisation sur les autres applications. Pour couper ce comportement :

  1. Sur votre clavier PC, appuyez sur les touches Windows + R, tapez mmsys.cpl et appuyez sur Entrée pour ouvrir la fenêtre de gestion audio classique.
  2. Dans l'onglet Lecture, faites un clic droit sur Haut-parleurs (USB Audio CODEC) et choisissez Propriétés.
  3. Allez dans l'onglet Statistiques avancées.
  4. Dans la section Mode Exclusif, décochez les deux cases :
    • [ ] Autoriser les applications à prendre le contrôle exclusif de ce périphérique
    • [ ] Donner la priorité aux applications en mode exclusif
  5. Cliquez sur Appliquer puis sur OK.

Répétez exactement la même procédure dans l'onglet Enregistrement en faisant un clic droit sur le périphérique Microphone (USB Audio CODEC).

[IMAGE 2 : Fenêtre des Statistiques Avancées du Périphérique Audio] Capture d'écran de l'onglet "Statistiques avancées" avec les deux cases du "Mode Exclusif" décochées.

2.2 Configurer le taux d'échantillonnage natif (48 000 Hz)

La carte son de l'Icom fonctionne de manière optimale à une fréquence d'échantillonnage de 48000 Hz (qualité DVD). Toujours dans l'onglet Statistiques avancées des propriétés audio, assurez-vous de sélectionner :

  • 2 canaux, 16 bits, 48000 Hz (Qualité DVD) pour la Lecture.
  • 1 canal, 16 bits, 48000 Hz (Qualité DVD) (ou 2 canaux selon les versions de pilotes) pour l'Enregistrement.
⚠️ Alerte Volume Windows : Pensez à vérifier l'onglet Niveaux des propriétés de lecture du périphérique USB Audio CODEC. Par défaut, Windows l'initialise souvent à 0 % ou en sourdine (Mute). Réglez-le entre 40 % et 60 % pour éviter de saturer ou d'émettre un signal muet.

3. Configuration Interne de l'Icom IC-7300

Pour que le poste accepte d'être piloté par l'ordinateur et de commuter sa source d'entrée audio sur la ligne USB, plusieurs paramètres doivent être ajustés dans le menu physique de la radio.

3.1 Réglages des Connecteurs (MENU > SET > Connectors)

Appuyez sur le bouton physique MENU de votre radio, touchez SET sur l'écran tactile, puis allez dans Connecteurs (Connectors) pour appliquer les réglages suivants :

  • DATA MOD (Source de modulation DATA) : Réglez impérativement sur USB. (Ce paramètre indique au poste que lorsqu'il émet en mode DATA (ex: USB-D), l'audio provient du câble USB et non du micro à main).
  • USB MOD Level (Volume d'entrée USB) : Réglez entre 30% et 50%. Une valeur trop basse rendra votre MP3 muet, une valeur trop haute fera saturer l'émission.
  • USB Serial Function (Fonction port USB) : Réglez sur CI-V.
[IMAGE 3 : L'écran tactile de l'IC-7300 - Menu Connecteurs] Capture de l'écran physique montrant les lignes "DATA MOD = USB" et "USB MOD Level".

3.2 Réglages de la liaison CAT (Connectors > CI-V)

Toujours dans le menu Connecteurs, entrez dans le sous-menu CI-V :

  • CI-V Baud Rate (Vitesse de liaison) : Réglez sur 115200 (ou configurez une vitesse identique dans notre application).
  • CI-V Address (Adresse physique) : Assurez-vous qu'elle est sur sa valeur d'usine par défaut, à savoir 94h.
  • CI-V USB Port (Liaison port USB) : Réglez sur Unlink from [REMOTE] (Déconnecté du jack Remote).

3.3 Comment entendre votre propre émission (La fonction MONITOR)

Par défaut, l'Icom coupe le haut-parleur en émission pour éviter l'effet Larsen. Si vous souhaitez entendre la lecture de votre fichier MP3 lors du lancement d'un appel automatique, vous devez activer le retour sonore de la radio :

  • Appuyez sur le bouton physique MENU du poste, puis touchez le bouton tactile MONITOR pour l'activer (il s'éclaire en bleu). Vous pouvez régler le niveau de retour à votre convenance.

4. Manuel d'Instruction de l'Application

Une fois le matériel et le système configurés, lancez le contrôleur CAT Rust. Voici comment utiliser ses différentes fonctions graphiques.

4.1 En-tête supérieur et Connexion

Dans la barre supérieure, vous trouverez l'état de votre connexion et le **Menu Principal ▾** :

  • 📂 Menu Principal ▾ : Un menu déroulant compact qui regroupe toutes les boîtes de dialogue de l'application (Configuration COM, Gestionnaire de mémoires SQL, Réglages des Gains, Outils CSV, Spectre et Lanceur d'appel). Cela libère l'espace de l'écran principal pour une lecture confortable.
  • Boutons Allumer / Éteindre (⏻) : Permettent de commander l'alimentation physique de la radio directement depuis l'ordinateur grâce à l'envoi d'une trame longue de réveil CI-V.
[IMAGE 4 : La barre d'en-tête de l'application] Vue rapprochée de la barre supérieure montrant le bouton "📂 Menu Principal ▾" et le voyant LED d'état de connexion.

4.2 Le cadran principal (VFO & Réglage de Fréquence)

Le cadran LCD affiche la fréquence active en gros caractères verts. Vous pouvez ajuster la fréquence de trois manières :

  • Le VFO rotatif virtuel : Faites glisser votre souris de gauche à droite sur le gros bouton rotatif gris pour monter ou descendre en fréquence, imitant le comportement d'un vrai bouton physique.
  • La molette de la souris : Survolez simplement le cadran LCD vert et utilisez la molette de votre souris pour vous accorder de façon ultra-rapide.
  • Le pas d'accord (TUNING STEP) : Cliquez sur n'importe quel chiffre du cadran LCD pour définir le pas de réglage (de 1 Hz à 1 MHz). Le chiffre sélectionné se met à clignoter en jaune. Vous pouvez également utiliser les flèches directionnelles de votre clavier pour monter/descendre ou changer de pas.

4.3 L'analyseur de spectre et la cascade (Waterfall)

L'analyseur de spectre FFT affiche en temps réel l'activité radio sous forme d'une courbe vectorielle dont la couleur varie dynamiquement (du Vert pour le bruit de fond au Rouge pour les signaux forts) :

  • Accord par clic : Cliquez n'importe où sur le graphe du spectre ou sur la cascade d'historique (Waterfall) pour accorder instantanément votre radio sur le signal visualisé. L'accord est automatiquement arrondi au kHz le plus proche.
  • Déplacement du curseur : Lorsque votre pointeur de souris survole l'un ou l'autre des graphiques, une barre jaune verticale suit fidèlement votre souris et affiche en direct la fréquence ciblée sous forme d'info-bulle flottante.
  • Contrôle du Span : Le sélecteur de Span vous permet d'ajuster la largeur de bande visualisée (de ±2.5 kHz à ±500 kHz). La synchronisation est bidirectionnelle : si vous changez le Span sur l'écran tactile de la radio, l'application se met à jour instantanément, et inversement.
[IMAGE 5 : Fenêtre de l'Analyseur de Spectre et du Waterfall] Vue de la fenêtre du spectre montrant la courbe thermique de Vert à Rouge, la cascade animée et la barre jaune du curseur avec sa bulle de fréquence.

4.4 Le Lanceur d'Appel Automatique & Balise (Keyer)

Le lanceur d'appel automatique est un outil puissant pour automatiser vos transmissions récurrentes (comme les appels CQ répétés). Il dispose de 20 mémoires de stockage programmables :

  • Routage audio automatique vers l'Icom : L'application énumère toutes vos cartes son et recherche automatiquement l'émetteur (USB Audio CODEC). Si l'Icom est raccordé, la modale se verrouille dessus et l'affiche en vert. Sinon, elle bascule en mode de repli sur vos haut-parleurs PC pour vos essais hors ligne. Vous pouvez également forcer le choix manuellement via le menu déroulant.
  • Uploader de fichier MP3 : Cliquez sur Uploader 📁 pour sélectionner un fichier d'appel MP3 sur votre disque dur. L'application se charge de :
    1. Créer le dossier local samples/ s'il n'existe pas.
    2. Copier physiquement le fichier sélectionné dans ce dossier local.
    3. Calculer automatiquement la durée exacte du MP3 et l'appliquer en tant que durée d'émission (TX).
    4. Sauvegarder immédiatement l'état dans la base de données SQL pour ne rien perdre au redémarrage.
  • Fonctionnement de l'automate : Cliquez sur ▶ DÉMARRER LA BOUCLE. L'application passe automatiquement la radio en émission (PTT + DATA s'ils sont cochés), lance la lecture du MP3 vers la carte son de l'Icom, affiche une barre de progression en temps réel, puis repasse en réception à la fin du chronomètre pour la durée de l'écoute spécifiée avant de recommencer le cycle.
  • Sécurité d'interruption absolue : À tout moment, si vous pressez la barre d'espace de votre clavier, cliquez sur le bouton de PTT de l'IHM, ou appuyez sur le bouton physique du micro à main de votre Icom, l'automate d'appel s'arrête instantanément, coupe le son MP3 et désactive le mode DATA pour vous redonner immédiatement le contrôle manuel complet du poste.

5. Liaison CAT et Tunnel avec MMSSTV

Notre application intègre un Proxy CAT / Bridge CI-V asynchrone. Cela vous permet d'interconnecter un logiciel tiers comme MMSSTV avec notre contrôleur pour qu'ils se partagent l'Icom en toute transparence [1].

5.1 Création de la paire virtuelle avec com0com ou VSPE

Puisque MMSSTV ne gère pas les ports COM supérieurs à 9, vous devez configurer une paire virtuelle utilisant des numéros bas (ex : **`COM2`** et **`COM4`**) à l'aide de votre émulateur de port série [1] :

  • com0com : Installez la version signée 64 bits. Dans l'utilitaire de configuration, cochez *use Ports class* pour vos deux ports, renommez l'un en COM2 et l'autre en COM4, puis cliquez sur *Apply* [1].
  • VSPE : Allez dans *Device > Create*, choisissez *Pair*, attribuez COM2 et COM4, puis validez [1].
[IMAGE 6 : Schéma du Tunnel de communication] Schéma explicatif : MMSSTV (COM4) <--> [Tunnel Virtuel] <--> Notre programme Rust (COM2) <--> [Liaison Physique] <--> IC-7300 (COM3 physique).

5.2 Activation du pont dans notre application

Ouvrez la Configuration COM de notre contrôleur, et dans la section *Pont CAT Virtuel*, sélectionnez ou saisissez manuellement : COM2 [1]. Cliquez sur connecter [1]. Le contrôleur écoute désormais les ordres sur ce canal virtuel [1].

5.3 Paramétrage de MMSSTV

Dans MMSSTV, allez dans Option > Setup MMSSTV :

  • Dans l'onglet TX, cliquez sur **Radio Command** :
    • Port : Choisissez **`COM4`** (l'autre extrémité de la paire com0com) [1].
    • Model : Sélectionnez un modèle Icom historique, par exemple **`IC-746`** ou **`IC-706`** [1]. (Notre Proxy CAT détectera dynamiquement l'adresse CI-V de ce modèle et y répondra à l'identique pour assurer la liaison sans surcharge réseau) [1].
    • Baud Rate : Choisissez la même vitesse (ex: 19200 ou 115200).
  • Dans l'onglet Misc, assurez-vous de sélectionner l'**USB Audio CODEC** de votre Icom pour l'entrée et la sortie son.
✓ Liaison validée : Si la configuration est correcte, changer la fréquence sur notre contrôleur Rust mettra instantanément à jour la fréquence de MMSSTV [1]. Inversement, cliquer sur une station SSTV dans MMSSTV accordera la radio physique, et lancer une transmission SSTV enclenchera automatiquement l'émission sur l'Icom [1].
