Contrôleur CAT Rust & MMSSTV via la passerelle com0com (Windows 64-bit)

Ce tutoriel vous guide pas à pas pour créer un pont de communication virtuel bidirectionnel asynchrone. Notre contrôleur Rust se connecte au port COM physique de votre émetteur-récepteur (ex : COM3), tout en écoutant l'extrémité virtuelle COM2. De son côté, MMSSTV se connecte à l'autre extrémité virtuelle COM4 pour lire la fréquence et piloter le PTT à la volée.

Étape 1 : Téléchargement des logiciels nécessaires

  • com0com v3.0.0.0 (Version signée 64-bit) :
    Page de téléchargement officielle sur SourceForge.
    Téléchargez et décompressez l'archive nommée com0com-3.0.0.0-i386-and-x64-signed.zip.
  • MMSSTV (Slow Scan TV) :
    Page officielle de MM HamSoft (MMSSTV Standard) ou la version modernisée MMSSTV YONIQ.

Étape 2 : Installation et renommage des ports dans com0com

Par défaut, l'installation de com0com crée une paire virtuelle nommée CNCA0 et CNCB0. Comme MMSSTV ne gère que les ports nommés classiquement (COM1 à COM8), nous devons obligatoirement les renommer :

  1. Décompressez l'archive de com0com et lancez l'installation (setup.exe).
  2. Une fois l'installation terminée, ouvrez votre menu Démarrer de Windows, cherchez le dossier com0com, faites un clic droit sur l'application Setup et choisissez "Exécuter en tant qu'administrateur" (requis pour enregistrer les modifications dans le registre Windows).
  3. Dans la fenêtre de configuration, cochez impérativement la case use Ports class située en haut à droite pour les deux ports. (Cette option permet à Windows de déclarer ces ports comme de vrais ports série de communication).
  4. Dans le champ de saisie textuelle de gauche (à la place de CNCA0), tapez : COM2.
  5. Dans le champ de saisie de droite (à la place de CNCB0), tapez : COM4.
  6. Cliquez sur le bouton Apply (Appliquer) en bas à droite.
  7. Windows va émettre un signal sonore d'ajout matériel et configurer les deux ports virtuels. Vous pouvez maintenant fermer l'utilitaire.
⚠️ Attention aux ports occupés : Si les ports COM2 ou COM4 sont déjà affectés à des périphériques physiques réels sur votre PC, choisissez d'autres numéros inférieurs à 9 libres (par exemple COM5 et COM7) dans l'utilitaire de configuration.

Étape 3 : Configuration de notre Contrôleur Rust

  1. Lancez notre application de contrôle CAT Rust.
  2. Ouvrez le menu déroulant 📂 Menu Principal ▾ et cliquez sur Configuration COM.
  3. Assurez-vous que le Port Série matériel principal est correctement connecté à votre radio (ex : COM3 de l'IC-7300, configuré à 115200 bauds).
  4. Dans la section 🔌 Pont CAT Virtuel (MMSSTV / Log) :
    • Dans le champ Port COM Virtuel, sélectionnez ou saisissez manuellement : COM2.
  5. Cliquez sur le bouton principal de l'en-tête de l'application : Connecter le Transceiver.

Le contrôleur Rust est maintenant raccordé à la radio sur le port COM3 physique et a ouvert une écoute asynchrone sur l'extrémité virtuelle COM2.

Étape 4 : Configuration de MMSSTV

  1. Lancez MMSSTV sur votre PC.
  2. Allez dans le menu supérieur : Option $\rightarrow$ Setup MMSSTV.
  3. Allez sur l'onglet TX :
    • Dans la section PTT (ou Radio Command selon la version), cliquez sur le bouton Radio Command.
    • Configurez les paramètres d'interconnexion ainsi :
      • Port : Sélectionnez COM4 (l'autre extrémité de notre tunnel com0com).
      • Model : Choisissez un émetteur Icom classique (ex : IC-746 ou IC-706). (Grâce à notre décodeur d'adresse dynamique, notre proxy Rust interceptera n'importe quelle adresse CI-V envoyée par MMSSTV et y répondra à l'identique).
      • Baud Rate : Choisissez la même vitesse (ex : 115200 ou 19200).
    • Cliquez sur OK pour enregistrer.
  4. Allez sur l'onglet Misc (Divers) pour router le flux audio :
    • Dans la section Sound Card, sélectionnez le périphérique USB Audio CODEC de l'Icom 7300 pour l'entrée (Input/RX) et pour la sortie (Output/TX).
    • Cliquez sur OK.

Étape 5 : Test de la synchronisation bidirectionnelle

✓ Liaison opérationnelle : Vous pouvez désormais tester la synchronisation en temps réel :
  • Sens Contrôleur → MMSSTV : Tournez le bouton rotatif VFO ou changez de bande dans l'application Rust. La fréquence affichée en haut à droite de MMSSTV se met à jour instantanément !
  • Sens MMSSTV → Contrôleur : Double-cliquez sur une station ou modifiez la fréquence dans le waterfall de MMSSTV. Notre contrôleur Rust reçoit l'ordre, ajuste son cadran local et règle la fréquence physique de votre IC-7300.
  • Émission SSTV : Cliquez sur TX dans MMSSTV. Le contrôleur Rust intercepte l'ordre, bascule la radio en mode DATA, enclenche le PTT physique de l'Icom, et MMSSTV module le son de l'image directement sur l'air !
